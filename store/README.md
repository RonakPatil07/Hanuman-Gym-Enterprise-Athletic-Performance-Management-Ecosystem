# GYM Website - Merch Page

A pixel-perfect recreation of the Figma design for a gym merchandise page.

## Features

- **Pixel-perfect design** matching the original Figma layout
- **Responsive design** that works on all screen sizes
- **High-quality images** extracted directly from Figma
- **Modern typography** using Outfit and Montserrat fonts
- **Interactive elements** including hover effects and form inputs

## Design Specifications

- **Colors**: Black background (#000000), White text (#FFFFFF), Lime accents (#B3DD24)
- **Typography**: 
  - Primary: Outfit (weights: 300, 400, 600, 700)
  - Secondary: Montserrat (weight: 400)
- **Layout**: 1440px max width, centered design
- **Images**: All images downloaded from Figma with proper cropping and optimization

2. **Hero Section**: Background image with overlay text
